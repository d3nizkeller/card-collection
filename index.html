        Служебные кнопки (обычно не нужны)

        Все игроки сайта автоматически подключены к главной комнате 7j8uytui — вводить код не нужно. Регистрация не нужна, но у комнаты есть логин и пароль: «Создать комнату» → придумайте логин и пароль комнаты → «Опубликовать». Друзья уже в главной комнате автоматически (или вводят её код → «Подключить») и сразу видят ваши паки. Создатель — тот, кто знает логин и пароль: только он редактирует паки и карточки и публикует изменения, остальные — участники в режиме «только просмотр». Изменения отправляются в комнату автоматически сразу после сохранения — даже если создатель тут же закрыл игру: правки допубликуются при следующем запуске. Участники получают обновления сами, примерно каждые 20 секунд (или мгновенно при возврате на вкладку) — без перезагрузки страницы. С другого устройства или после очистки данных браузера нажмите «Я создатель — войти» и введите логин и пароль комнаты. В облаке хранится только хэш пароля (не сам пароль), поэтому забытый пароль восстановить нельзя — запишите его.

        Продвинутый режим: своя база Firebase (необязательно — простое хранилище работает и так)

        Своя база надёжнее и держит каталог до 4 МБ. Создаётся кликами за 5 минут, код писать не нужно:

        1. Откройте console.firebase.google.com → «Создать проект» (бесплатно, название любое).
        2. Слева: Build → Realtime Database → «Create Database» → регион любой → режим «test mode» (чтение/запись открыты).
        3. На вкладке Realtime Database скопируйте URL базы вида https://имя-проекта-default-rtdb.firebaseio.com (или …firebasedatabase.app).
        4. Вставьте URL в поле ниже → «Сохранить URL» → «Создать комнату» → задайте логин и пароль комнаты → «Опубликовать» → передайте код комнаты игрокам.
        5. Игроки: вставляют тот же URL и код комнаты → «Подключить». Готово (логин и пароль им не нужны — они только смотрят и получают паки).

        Чтобы вернуться в простой режим — очистите поле URL и нажмите «Сохранить URL». Стандартный набор игры не синхронизируется. Нет сети — игра работает локально.
