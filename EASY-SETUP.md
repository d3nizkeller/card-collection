# Поднять сервер — просто

Коротко: **нужно сделать 3 действия руками, остальное сделает одна команда.**

Сервер — это бесплатный Cloudflare Worker. Он считает деньги, спины, джекпот,
паки, биржу и админку. Пока он не поднят, игра работает как раньше (на локальной
логике) — ничего не сломано, просто защиты от подделки баланса нет.

```
┌─ ЧТО ДЕЛАЕТЕ ВЫ ────────────────────────────────────────────┐
│ 1. Зарегистрироваться на Cloudflare          ~3 минуты      │
│ 2. Создать API-токен (4 галочки)             ~2 минуты      │
│ 3. Запустить:  npm run nexus                 ~2 минуты      │
└─────────────────────────────────────────────────────────────┘
```

---

## Шаг 1. Аккаунт Cloudflare (бесплатно, карта не нужна)

1. Откройте **https://dash.cloudflare.com/sign-up**
2. Введите e-mail и пароль → **«Sign up»**
3. Придёт письмо — нажмите в нём кнопку подтверждения
4. Дальше Cloudflare спросит про тариф: выбирайте **Free / Пропустить**
   (бесплатного хватает с огромным запасом: 100 000 запросов в сутки,
   игра делает 1 запрос на спин)
5. Если спросит «добавить сайт» — **пропустите**, это не нужно

Готово. Аккаунт создан.

---

## Шаг 2. API-токен

Токен — это ключ, которым команда деплоя входит в ваш Cloudflare.
Создаётся так:

1. В правом **верхнем** углу нажмите на **значок человечка** (профиль)
2. Выберите **«My Profile»**
3. Вверху вкладка **«API Tokens»**
4. Кнопка **«Create Token»** → прокрутите вниз → **«Create Custom Token»**
   (рядом с надписью *Get started with API Tokens*)
5. Заполните ровно так:

   | Поле | Что выбрать |
   |---|---|
   | Token name | `nexus-card` |
   | Permissions (1-я строка) | `Account` • `Workers Scripts` • `Edit` |
   | Permissions (2-я строка, «+ Add more») | `Account` • `D1` • `Edit` |
   | Account Resources | `Include` • **ваш аккаунт** |
   | Client IP Address Filtering | пусто |
   | TTL | пусто |

6. **«Continue to summary»** → **«Create Token»**
7. Скопируйте токен (длинная строка из букв и цифр). **Он показывается один раз.**

> 🔒 Токен даёт доступ только к Workers и D1 — **не** к вашим сайтам, DNS,
> платежам и не к GitHub. После деплоя его можно отозвать в том же разделе
> (кнопка «Roll»), а сервер продолжит работать: токен нужен только для установки.

## Шаг 3. Одна команда

В папке репозитория:

```bash
npm run nexus
```

Скрипт спросит токен (ввод не отображается — это нормально), логин и пароль
Студии, и дальше **всё сделает сам**:

| # | Что делает | Раньше это было |
|---|---|---|
| 1 | проверяет Node и ставит wrangler | `npm install` |
| 2 | находит ваш аккаунт Cloudflare | — |
| 3 | включает поддомен `workers.dev` | руками в дашборде |
| 4 | создаёт базу `nexus-bank` | `wrangler d1 create` |
| 5 | вписывает `database_id` в `wrangler.toml` | копировать руками |
| 6 | генерирует `NX_SECRET` и `NX_SETUP_KEY` | `openssl rand -hex 32` |
| 7 | деплоит воркер | `wrangler deploy` |
| 8 | загружает оба секрета | `wrangler secret put` ×2 |
| 9 | проверяет `/api/health` | `curl` |
| 10 | переносит игроков, банк, зал славы, каталог | `migrate.mjs` с 6 аргументами |
| 11 | вписывает адрес сервера в `index.html` | править HTML руками |
| 12 | сохраняет ключи в `server/.nexus.local.json` | запоминать самому |

В конце напечатает адрес сервера и что именно перенесено.

**Что нужно для входа в Студию:** тот же логин и пароль, что и сейчас.
Учётка переносится прежним хэшем, придумывать новый пароль не надо.

### План Б — без терминала

Если Node.js не установлен или команда не запускается: создайте токен по шагу 2
и передайте его ассистенту — деплой и перенос данных будут сделаны без единой
команды с вашей стороны. Токен после этого сразу отзовите («Roll»).

## Шаг 4. Проверить, что получилось

1. Откройте адрес из конца работы скрипта, добавив `/api/health`:
   `https://nexus-card-api.<ваш-поддомен>.workers.dev/api/health`
   Должно быть `{"ok":true,…,"store":"d1","secret":true}`
2. Откройте игру → **Студия** → войдите своим паролем.
   Панель должна показывать реестр игроков и банк (а не надпись «сервер не подключён»).
3. Через ~1 минуту GitHub Pages обновит сайт — обычный игрок получит серверный
   режим автоматически, ничего настраивать не нужно.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `Cloudflare не принял токен` | Токен скопирован не полностью или создан без прав `Workers Scripts → Edit` и `D1 → Edit`. Создайте заново. |
| `не включён поддомен workers.dev` | dash.cloudflare.com → **Workers & Pages** → справа **«Your workers.dev subdomain»** → придумайте имя → **Save**. Затем `npm run nexus` ещё раз. |
| `npm: command not found` | Нет Node.js → https://nodejs.org, кнопка **LTS**, установить и перезапустить терминал. |
| `Не удалось создать базу D1` | В токене нет права `Account → D1 → Edit`. |
| Скрипт упал на середине | Просто запустите `npm run nexus` ещё раз: всё сделанное сохранено в `server/.nexus.local.json`, скрипт продолжит с того же места и ничего не продублирует. |
| `Ничего не найдено: 0 игроков…` | Скрипт **специально отказался** отправлять пустоту, чтобы не обнулить банк. Проверьте, что читается документ `nexus-tcg-jackpot-v3` и комната каталога (`--catalog-room`, по умолчанию берётся из `assets/app.js`). |
| Хочу только посмотреть, что перенесётся | `node server/migrate.mjs --api <адрес> --dry-run` |

## Что осталось на клиенте (честно)

* **Дурак и Арена** — сама партия считается в браузере; ставка и выплата уже
  проходят через сервер, но воспроизведения партии на сервере нет.
* **11 достижений** арены/дурака/альбомов сервер не может проверить по своим
  счётчикам — они выдаются один раз на id и строго в размере из
  `assets/nx-rules.js`. Завысить сумму нельзя, «выбить всё сразу» — можно,
  но это разовая ограниченная сумма.
* **Скидочные окна паков** считает клиент, но сервер принимает цену только в
  коридоре `цена×10 %…цена`. Купить дешевле нельзя.

Подробности — раздел 7 в `server/README.md`.

## Отдельно: токен GitHub

GitHub-токен (`ghp_…`), если он где-то засветился, даёт **полный доступ к
аккаунту**: можно удалить репозитории, читать приватные, менять e-mail.
Отзывается здесь: **github.com → Settings → Developer settings → Personal
access tokens → Tokens (classic) → Revoke**.

Правильно создавать **Fine-grained token** только на один репозиторий и только
с правом `Contents: Read and write` — тогда утечка не страшна.
После деплоя сервера GitHub-токен для игры вообще не нужен: сайт обновляется
через GitHub Pages из ветки `main`.
