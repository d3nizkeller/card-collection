## ✨ Описание

**Собери Свою Коллекцию Карточек** - это интерактивная платформа для коллекционирования и обмена карточками с друзьями. Просто создай комнату, поделись кодом и начни собирать уникальные карточки вместе с командой!

## 🎮 Как Играть

1. **Открой приложение** - перейди по ссылке ниже
2. **Создай или войди в комнату** - используй простой код комнаты (без регистрации!)
3. **Собирай карточки** - открывай новые карточки и пополняй свою коллекцию
4. **Делись с друзьями** - отправь код комнаты и играйте вместе

## 🌟 Особенности

- ✅ **Без регистрации** - просто введи код комнаты и начни играть
- 🔄 **Автоматические обновления** - все изменения синхронизируются в реальном времени
- 👥 **Мультиплеер** - играй с друзьями в одной комнате
- 🎨 **Красивый интерфейс** - приятный дизайн и анимации
- 📱 **Работает везде** - доступен на любом устройстве через браузер
