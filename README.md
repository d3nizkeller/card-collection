# 🎮 Инструкция: Как получить обновления карт и паков

## 1️⃣ Перейдите на сайт
🔗 **[https://d3nizkeller.github.io/card-collection/](https://d3nizkeller.github.io/card-collection/)**

## 2️⃣ Откройте раздел «Студия»
 В верхнем меню справа нажмите на вкладку **«Студия»** (см. скриншот — это последняя кнопка в меню).

## 3️⃣ Введите код комнаты
📋 Скопируйте этот код:
# **`7j8uytui`**
⌨️ Вставьте его в поле ввода в разделе «Студия».

## 4️⃣ Подключитесь и получите обновления
🔘 Нажмите кнопку **«Подключить»**
 Затем нажмите кнопку **«Получить»**

✨ **Готово!** Все паки и карты Студии станут общими и обновятся автоматически!
